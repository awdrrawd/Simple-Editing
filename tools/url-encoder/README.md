# 🔗 URL 編碼 / 解碼器 · 純瀏覽器工具

編碼與解碼網址參數，支援 encodeURIComponent 和 decodeURIComponent。

🔗 線上使用：`/tools/url-encoder/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **URL 編碼**：將普通文字轉換為可以安全放入 URL 的編碼格式（使用 encodeURIComponent）。
- **URL 解碼**：將已編碼的 URL 參數轉回原始文字（使用 decodeURIComponent）。
- **即時結果**：輸入後立即顯示編碼或解碼結果。
- **一鍵複製**：點擊即可複製結果到剪貼簿。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後預設在「編碼」模式。
2. 在左側文字區域貼上或輸入要編碼的文字。
3. 按「編碼」按鈕，結果會顯示在右側文字區域。
4. 若要解碼，點擊頂部的「解碼」標籤切換到解碼模式。
5. 在左側文字區域貼上或輸入要解碼的已編碼文字。
6. 按「解碼」按鈕，結果會顯示在右側文字區域。
7. 點擊「複製結果」按鈕將結果複製到剪貼簿。

## 技術說明

- 所有處理都在瀏覽器本機完成，不會將您的資料傳送到任何伺服器。
- 編碼使用 JavaScript 的 `encodeURIComponent()` 函數。
- 解碼使用 JavaScript的 `decodeURIComponent()` 函數。
- 這兩個函數會正確處理特殊字符、空格、中文等 Unicode 字符。
- 編碼結果適合用於 URL 查詢參數、路徑片段等場所。
- 解碼時若輸入不是有效的編碼格式，會顯示錯誤訊息。
