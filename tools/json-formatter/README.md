# 🧮 JSON 格式化器 · 純瀏覽器工具

美化、壓縮與驗證 JSON，支援標準格式，即時顯示結果。

🔗 線上使用：`/tools/json-formatter/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **JSON 美化**：將壓縮的 JSON 格式化為易於閱讀的結構，支援縮進自訂。
- **JSON 壓縮**：移除所有空白字元，將 JSON 壓縮為最小尺寸。
- **JSON 驗證**：即時驗證 JSON 語法是否正確，提供錯誤位置提示。
- **即時結果**：輸入後立即顯示格式化、壓縮或驗證結果。
- **一鍵複製**：點擊即可複製結果到剪貼簿。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後預設在「美化」模式。
2. 在左側文字區域貼上或輸入 JSON 內容。
3. 選擇操作模式：
   - **美化**：格式化 JSON 為易讀形式
   - **壓縮**：移除所有空白字元壓縮 JSON
   - **驗證**：檢查 JSON 語法是否正確
4. 結果會即時顯示在右側文字區域。
5. 點擊「複製結果」按鈕將結果複製到剪貼簿。

## 技術說明

- 所有處理都在瀏覽器本機完成，不會將您的 JSON 資料傳送到任何伺服器。
- 使用 `JSON.parse()` 驗證 JSON 語法正確性。
- 美化使用 `JSON.stringify()` 配合縮進參數。
- 壓縮使用正則表達式移除所有空白字元（空格、 tab、換行等）。
- 驗證過程中若發現錯誤，會顯示具體的錯誤訊息和位置。
