# 🔊 聲音編輯器 · 純瀏覽器工具

載入音訊檔案，調整音量與音高（會影響播放速度），即時預覽波形，並可混合多軌道播放或下載混合後的 WAV 檔案。全部在瀏覽器本機完成，不會上傳任何資料。

🔗 線上使用：`/tools/audio-editor/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **多檔案載入**：支援一次選取多個音訊檔案（MP3、WAV、OGG 等常見格式）。
- **即時波形顯示**：每個載入的音訊會顯示簡易波形，方便快速檢視。
- **音量與音高調整**：每條軌道皆有獨立的音量滑桿（0~1）與音高滑桿（0.5~2.0），音高會改變播放速度及音調。
- **即時混合播放**：所有軌道會即時混合播放，調整參數時會立即反應在混合音訊上。
- **播放控制**：提供「播放全部」、「停止全部」按鈕，亦可逐軌道播放/暫停。
- **下載混合音訊**：混合後可下載為單一 WAV 檔案（16-bit PCM，立體聲，採樣率 44.1kHz）。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後點擊「選取音訊檔案（可多選）」，選擇一或多個音訊檔案。
2. 按下「載入音訊」按鈕，待載入完成後會出現每個檔案的軌道條目。
3. 每條軌道會顯示：
   - 檔案名稱
   - 播放/暫停按鈕
   - 音量滑桿（預設 1.0）
   - 音高滑桿（預設 1.0，影響播放速度與音調）
   - 簡易波形圖
   - 進度條（播放中顯示）
4. 若想調整音量或音高，直接移動對應滑桿，變化會即時影響該軌道的輸出。
5. 按「播放全部」開始混合播放，「停止全部」停止所有軌道。
6. 播放完成後（或隨時）可點「下載混合音訊」以下載目前混合結果為 `mixed_output.wav`。
7. 若要移除某條軌道，點擊該軌道的「移除」按鈕。

## 技術說明

- 使用 Web Audio API 進行音訊解碼、混合與播放。
- 音訊解碼靠 `AudioContext.decodeAudioData`，支援的格式取決於瀏覽器的原生解碼能力（MP3、WAV、OGG 在現代瀏覽器中普遍支援）。
- 每條軌道透過 `GainNode` 控制音量，`AudioBufferSourceNode.playbackRate` 控制音高（同時改變播放速度）。
- 混合音訊的下載利用 `OfflineAudioContext` 將所有軌道離線渲染到緩衝區，然後將 Float32 音訊樣本編碼為 16-bit PCM WAV 格式並產生 Blob 下載。
- 所有運算均在瀏覽器主執行緒或音訊執行緒完成，不會將您的音訊檔案傳送至任何伺服器。
- 波形顯示採用簡單的 Canvas 繪製，僅顯示單聲道的輪廓，目的是提供即時視覺回饋而非專業波形編輯。

## 注意事項

- 受瀏覽器記憶體限制，一次載入過大或過多的音訊檔案可能導致頁面變慢或無法解碼。
- 音高滑桿會同時改變播放速度與音調（類似變速播放），若希望只改變音調而不改變速度，需額外使用階級拉伸（time‑stretch）演算法，此版本未實作。
- 下載的混合音訊長度會以目前所有軌道中最長的播放位置為準（若有軌道尚未播放完），建議在播放完畢後再下載以獲得完整混合結果。
- 若瀏覽器不支援 `OfflineAudioContext`（極少見），下載功能將無法使用，但播放與即時調整仍可正常運作。
