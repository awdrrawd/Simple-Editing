# 📝 格式小幫手 · Markdown Buddy

一個左寫右看的 Markdown 編輯器。左邊輸入 Markdown 原始碼，右邊即時顯示排版後的樣子，工具列可以一鍵套用常用格式，不需要背 Markdown 語法。

🔗 線上使用：`/tools/markdown-editor/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **即時預覽**：左邊編輯、右邊同步渲染，支援 GitHub 風格的 Markdown（表格、刪除線、程式碼區塊語法高亮）。
- **工具列一鍵格式化**：
  - 標題 H1 / H2 / H3
  - 粗體、斜體、粗斜體、刪除線
  - 縮排 / 退縮排
  - 靠左 / 置中 / 靠右對齊（透過插入 HTML `<div align>`，需要支援 HTML 的檢視器如 GitHub 才看得出效果）
  - 引用區塊、程式碼區塊
  - 項目符號清單、編號清單、待辦清單
  - 分隔線、強制換行
  - 插入連結、插入圖片
  - 插入表格（可自訂列數、欄數、對齊方式）
  - 自動產生目錄（依文件中的 `#` 標題產生可跳轉的 TOC）
- **清除格式**：選取文字（或不選就整篇）按下「🧹 清除格式」，把 Markdown 符號去掉、只留下純文字。
- **匯入 / 匯出**：可匯入現有的 `.md` 檔案繼續編輯；匯出時可選擇下載成 `.md`，或開啟瀏覽器列印視窗另存為 PDF。
- **快捷鍵**：`Ctrl+B` 粗體、`Ctrl+I` 斜體、`Ctrl+K` 插入連結。
- **字數統計**：即時顯示字數與字元數估計。
- **手機版分頁**：畫面較窄時，編輯區與預覽區會變成「✍️ 手稿」／「📖 預覽」兩個分頁，方便手機操作。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後直接在左側編輯區輸入 Markdown（已預先放了一段範例文字示範各種語法）。
2. 想套用格式時，可以用滑鼠選取文字後按工具列按鈕，或直接把游標移到想插入的位置按按鈕。
3. 檔名可以在上方「檔名」欄位自訂，會用在匯出檔案時的檔名。
4. 編輯完成後，用右上角「複製」複製全部原始碼，或用「匯出」下載 `.md` / PDF。

## 技術說明

- Markdown 解析：[marked.js](https://github.com/markedjs/marked)
- 內容清理（避免 XSS）：[DOMPurify](https://github.com/cure53/DOMPurify)
- 程式碼語法高亮：[highlight.js](https://github.com/highlightjs/highlight.js)
- 所有處理都在瀏覽器本機完成，不會把你輸入的內容傳到任何伺服器。
