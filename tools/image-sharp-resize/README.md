# 🔍 銳利圖片縮放 · 純瀏覽器工具

使用高品質演算法（Lanczos 3）縮放圖片，縮小時保留銳利度與細節，特別適合 PNG。

🔗 線上使用：`/tools/image-sharp-resize/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **高品質縮放**：內建 Lanczos 3 演算法，縮小時保留銳利度與細節。
- **多種演算法**：可選 Lanczos 3（高品質）、雙線性、最近鄰。
- **靈活輸入**：可直接指定寬高（像素），或按比例縮放（百分比）。
- **即時預覽**：處理後立即顯示結果圖片，並顯示尺寸變化資訊。
- **一鍵下載**：下載處理後的圖片，檔名自動加上 `_resized` 後綴。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後點選「選取圖片檔案」上傳圖片（支援 PNG、JPEG、WebP、GIF 等）。
2. 選擇縮放演算法（預設 Lanczos 3）。
3. 輸入目標寬度和高度（像素），或輸入比例百分比（若寬高皆為空則使用比例）。
4. 按「進行縮放」處理圖片。
5. 處理完成後會顯示預覽圖片，並顯示原始尺寸與新尺寸。
6. 按「下載結果」下載處理後的圖片。

## 技術說明

- 使用 [Pica](https://github.com/nodeca/pica) 庫實現 Lanczos 3 高品質縮放。
- 雙線性與最近鄰演算法使用 Canvas 的 `drawImage` 和 `imageSmoothingQuality`。
- 所有處理都在瀏覽器本機完成，不會把你上傳的圖片傳到任何伺服器。
- 支援的圖片格式取決於瀏覽器的 `decode` 能力，常見的 PNG、JPEG、WebP、GIF 均可。
