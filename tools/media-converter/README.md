# 🎞️ 媒體轉換器 · 純瀏覽器工具

影片、音訊轉檔與裁切，支援常見格式，使用純瀏覽器的 ffmpeg.wasm。

🔗 線上使用：`/tools/media-converter/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **格式轉換**：支援多種影片和音訊格式間的轉換（MP4, WebM, MP3, WAV 等）。
- **時間裁切**：可選擇開始和結束時間點，只轉換所需片段。
- **參數調整**：可調整解析度、位元率、幀率等參數。
- **即時預覽**：轉換前可預覽原始媒體檔案。
- **進度顯示**：顯示轉換進度和預估剩餘時間。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後點擊「選取媒體檔案」上傳您的影片或音訊檔案。
2. 檔案載入後會顯示媒體資訊（長度、解析度、位元率等）。
3. 選擇目標格式（如 MP4、MP3、WebM、WAV 等）。
4. （可選）調整時間範圍：設定開始和結束時間點進行裁切。
5. （可選）調整轉換參數：解析度、位元率、幀率等。
6. 按「開始轉換」按鈕。
7. 轉換完成後會顯示下載連結，點擊即可下載轉換後的檔案。
8. 整個過程都在瀏覽器中完成，不會上傳任何檔案到伺服器。

## 技術說明

- 使用 [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) 在瀏覽器中執行 FFmpeg。
- 所有媒體處理都在瀏覽器本機完成，使用 WebAssembly 技術。
- 支援的輸入格式取決於瀏覽器的 File API 和 ffmpeg.wasm 的解碼能力。
- 支援的輸出格式包括：MP4, WebM, MP3, WAV, OGG, GIF 等。
- 轉換過程中會佔用一定的瀏覽器記憶體，較大檔案可能需要較多資源。
- 不會將您上傳的媒體檔案或轉換結果傳送到任何伺服器。
