# 🎞️ 媒體轉換器

在瀏覽器內使用 ffmpeg.wasm 轉換或裁切影片與音訊，不會上傳檔案。

- 影片：MP4 (H.264)、WebM (VP8)、Ogg Theora、GIF。
- 音訊：MP3、Ogg Vorbis、WAV、AAC。
- 裁切：輸入開始與結束秒數；影片輸出 MP4，音訊輸出 MP3。
- 結果可直接預覽、下載；同一格式可以重複轉檔。

選取檔案及目標格式後按「轉換」。裁切頁的結束時間須大於開始時間。處理時會顯示進度與狀態，完成後產生下載連結。GIF 採 15 FPS、寬 320 px；目前沒有自訂位元率或解析度面板。

頁首「主題、語系、回首頁」與全站一致。引擎使用本機附帶的單執行緒 core，首次轉檔需載入約 32 MB，無需跨來源隔離標頭。請使用支援 WebAssembly 的現代瀏覽器，輸入格式以引擎可解碼的格式為準。
