# 🔄 CSV ↔ JSON 轉換器 · 純瀏覽器工具

上傳 CSV 檔案轉為 JSON 結構，或貼上 JSON 轉為 CSV 檔案。全部在瀏覽器本機完成，不會上傳任何資料。

🔗 線上使用：`/tools/csv-converter/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **CSV → JSON**：上傳 CSV 檔案，可選擇是否將第一行視為標題，是否自動轉換數據類型，轉換後可預覽、複製或下載 JSON。
- **JSON → CSV**：貼上 JSON 文字或上傳 JSON 檔案，轉換為 CSV 格式，支援標準 JSON 陣列或物件，轉換後可預覽、複製或下載 CSV。
- **即時預覽**：轉換結果立即顯示在文字區域中，方便檢查。
- **一鍵複製與下載**：轉換後可直接複製結果或下載為檔案。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

### CSV 轉 JSON
1. 開啟頁面後預設在「CSV → JSON」標籤。
2. 點擊「選取 CSV 檔案」上傳您的 CSV 檔案（亦可拖放）。
3. 勾選「第一行為標題」若您的 CSV 第一行為欄位名稱。
4. 勾選「自動轉換數據類型」讓數字與布林值在 JSON 中保持為相應類型（否則全部為字串）。
5. 按「轉換為 JSON」按鈕。
6. 轉換後的 JSON 會顯示在下方文字區域，可點「複製結果」複製或「下載 JSON」下載 .json 檔案。

### JSON 轉 CSV
1. 點擊頂部的「JSON → CSV」標籤切換。
2. 可選擇：
   - 貼上 JSON 文字在文字區域中。
   - 或點擊「選取檔案」上傳 .json 檔案。
3. 按「轉換為 CSV」按鈕。
4. 轉換後的 CSV 會顯示在下方文字區域，可點「複製結果」複製或「下載 CSV」下載 .csv 檔案。

## 技術說明

- 使用 [PapaParse](https://www.papaparse.com/) 庫進行 CSV 的解析與序列化。
- 所有處理都在瀏覽器本機完成，不會將您的檔案或資料傳送到任何伺服器。
- 支援的檔案類型：CSV（文字/csv）與 JSON（應用/json）。
- 在 CSV → JSON 模式中，空白行會被自動跳過。
- 在 JSON → CSV 模式中，若輸入為單一 JSON 物件，會自動視為一筆資料的陣列進行轉換。
