# 🔐 雜湊計算器 · 純瀏覽器工具

輸入文字或檔案，計算 MD5、SHA-1、SHA-256 等雜湊值。所有計算在瀏覽器本機完成，不會上傳您的資料。

🔗 線上使用：`/tools/hash-calculator/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **多種雜湊演算法**：支援 MD5、SHA-1、SHA-256、SHA-384、SHA-512。
- **文字或檔案輸入**：可直接貼上文字，或選取檔案計算其雜湊值。
- **即時結果**：計算完成後立即顯示十六進位雜湊值。
- **一鍵複製**：點擊即可複製雜湊值到剪貼簿。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後選擇輸入方式：
   - 貼上文字：在文字區域輸入要計算雜湊的內容。
   - 選取檔案：點擊「選取檔案」上傳要計算雜湊的檔案。
2. 從下拉選單選擇雜湊演算法（預設 SHA-256）。
3. 按「計算雜湊」按鈕。
4. 雜湊值會以十六進位字串顯示在結果區域。
5. 點擊「複製」或結果旁的「複製」按鈕將雜湊值複製到剪貼簿。

## 技術說明

- 使用 Web Crypto API (`crypto.subtle.digest`) 進行所有雜湊計算。
- 所有處理都在瀏覽器本機完成，不會把您輸入的文字或檔案傳到任何伺服器。
- 支援的演算法取決於瀏覽器的 Web Crypto API 實作，現代瀏覽器均支援上述五種常見演算法。
- 文字輸入會自動轉換為 UTF-8 位元組進行雜湊計算。
