# 🎯 SVG 優化器 · 純瀏覽器工具

貼上 SVG 或選取檔案，移除冗餘資訊、縮短顏色值、清理未使用的 ID 等，讓 SVG 檔案更小、更乾淨。全部在瀏覽器本機完成，不會上傳任何資料。

🔗 線上使用：`/tools/svg-optimizer/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **即時優化**：使用 SVGO 進行常見優化，如移除不必要的 viewBox、清理 ID、移除 metadata、轉換顏色為縮寫形式等。
- **進階選項**：可自行開關各個優化插件，依需求客製化優化程度。
- **預覽與比較**：優化後會即時顯示 SVG 預覽，並顯示大小減少百分比。
- **一鍵複製與下載**：優化完成後可直接複製結果或下載 `.svg` 檔案。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後選擇輸入方式：
   - 貼上 SVG：在文字區域內貼上完整的 SVG 程式碼。
   - 選取檔案：點擊「選取檔案」上傳 `.svg` 檔案（亦可拖放）。
2. （可選）調整「優化選項」中的勾選框，開啟或關閉特定優化（預設皆為開啟）。
3. 按「優化 SVG」按鈕。
4. 優化後的 SVG 會顯示在下方文字區域，同時會出現預覽畫面與大小減少資訊。
5. 點擊「複製結果」將優化後的 SVG 複製到剪貼簿，或點「下載 SVG」儲存為檔案。

## 技術說明

- 使用 [SVGO](https://github.com/svg/svgo) 庫（版本 2.8.0）透過 Skypack CDN 引入，所有優化運算都在瀏覽器本機完成。
- 支援的 SVG 格式取決於瀏覽器的解析能力，標準的 SVG 1.1 與 SVG 2 特性均可處理。
- 優化插件皆為官方 SVGO 插件，可透過勾選框開關，對應的插件名稱如下：
  - `removeViewBox`：移除不必要的 viewBox 屬性
  - `cleanupIDs`：移除未使用的 ID 並壓縮所用 ID
  - `removeMetadata`：移除 `<metadata>` 與編輯器非必要元資料
  - `convertColors`：將 `rgb()`、`hsl()` 等顏色轉為十六進位縮寫（如 `#fff`）
  - `removeDimensions`：在有 viewBox 的情況下移除寬高屬性，避免重複定義
- 不會將您上傳的 SVG 或貼上的內容傳送到任何伺服器。
