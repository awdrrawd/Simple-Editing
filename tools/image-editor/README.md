# 🖼️ 圖片編輯器 · 純瀏覽器圖片編輯

一個純前端（不需伺服器、不上傳檔案）的圖片編輯器，分成「靜態圖片」與「動態圖片（GIF / APNG）」兩種模式，切換上方分頁即可。

🔗 線上使用：`/tools/image-editor/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 載入圖片

- 點「📂 載入圖片」選檔案，或直接把圖片拖曳到頁面任何地方。
- 靜態模式支援 JPG / PNG / WebP，並可用「📋 貼上圖片」直接貼上剪貼簿裡的圖片。
- 動態模式支援 GIF / APNG。
- 「重設為原圖」可以隨時放棄所有調整，回到剛載入時的狀態。
- 完成後用右上角「⬇ 下載 PNG」（動圖模式則在「輸出設定」面板匯出）。

## 靜態圖片模式

側邊工具列有五個分頁：

- **去背（色彩去背）**：用「🎯 選取顏色」在圖片上點選要去除的背景色（色彩去背 / chroma key），再用「容許度」「邊緣羽化」滑桿調整去背範圍與邊緣柔化程度，勾選「修正邊緣色溢」可以減少邊緣殘留的背景色暈。按「套用這次去背」確認，或「還原上一步」復原。
- **縮放（維持畫質）**：輸入寬高（可鎖定長寬比）或用百分比滑桿縮放，並可選擇「高品質（逐步縮小）」或「標準（單次縮放）」演算法。
- **裁切**：可選常用比例（1:1、4:3、3:4、16:9、9:16 或自由），也能直接輸入 X／Y／寬／高的精確數值。
- **調色**：亮度、對比、飽和度、色相偏移四個滑桿即時調整，可隨時「重設滑桿」或「還原上一步」。
- **轉 SVG（實驗性）**：把點陣圖向量化成 SVG，可調整顏色數量、線條銳利度、弧度平滑度，並可選擇統一填色或加上邊框（染色 / Tint），完成後可下載 `.svg`。

每個面板的「預覽底色」（棋盤透明 / 白 / 黑 / 自訂顏色）可以切換畫布背景，方便檢查去背效果。

## 動態圖片模式（GIF / APNG）

側邊工具列有八個分頁：

- **去背**：與靜態模式相同的色彩去背功能，套用到全部畫格。
- **縮放 / 調色**：同時調整整個動圖的尺寸與色彩。
- **裁切**：套用到全部畫格的裁切功能。
- **字幕**：在動圖上疊加文字（可設定文字內容與顏色），常用來做迷因圖或標註說明。
- **速度 / 抽幀**：調整播放速度，或抽掉部分畫格以縮小檔案。
- **畫格編輯**：逐格檢視、插入或刪除單一畫格。
- **影片轉動圖**：上傳一段影片，轉換成 GIF / APNG 動圖。
- **輸出設定**：設定完成後在這裡匯出最終的動圖檔案。

## 提醒

- 所有處理都在你的瀏覽器裡本機完成（使用 Canvas / `gif.js` / `imagetracerjs` 等函式庫），圖片不會上傳到任何伺服器。
- 「轉 SVG」與部分動圖功能標示為「實驗性」，複雜圖片或大檔案的處理時間可能較長，請耐心等候。
