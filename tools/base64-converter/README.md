# 🔤 Base64 · 純瀏覽器工具

任意檔案或文字 ⇄ Base64 編解碼，支援所有檔案類型，產出標準 Base64 字串。

🔗 線上使用：`/tools/base64-converter/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **編碼**：選擇檔案或貼上文字，產出標準 Base64 字串（不含 data:URL 前綴）。
- **解碼**：貼上 Base64 字串，可選擇輸出為純文字或下載為檔案。
- **即時預覽**：編碼/解碼結果即時顯示，並顯示檔案大小資訊。
- **複製與下載**：一鍵複製結果或直接下載解碼後的檔案。
- **主題／語言**：右上角可切換亮／暗主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 開啟頁面後選擇「編碼」或「解碼」模式。
2. 編碼：選擇檔案或貼上文字 → 按「編碼為 Base64」。
3. 解碼：貼上 Base64 字串 → 選擇輸出類型（純文字/下載檔案） → 按「解碼」。
4. 若選擇下載檔案，請先填寫檔案名稱（含副檔名）。
5. 編碼完成後可點「複製結果」將 Base64 字串複製到剪貼簿。
6. 解碼為文字時結果會顯示在畫面上；解碼為檔案時會觸發下載。

## 技術說明

- 所有處理都在瀏覽器本機完成，使用 JavaScript 的 `atob` 和 `btoa` 進行 Base64 轉換。
- 編碼檔案時使用 `FileReader` 讀取為 ArrayBuffer，再轉為 Base64。
- 解碼時先移除空白字元，再使用 `atob` 取得二進位資料，依輸出類型解碼為 UTF-8 文字或建立 Blob 下載。
- 不會把你輸入的內容傳到任何伺服器。
