# ⏱️ AI Cooldown · 冷卻時間記事器

用來記錄「哪個 AI 服務、哪個帳號，還要等多久才能再用」的小工具。適合同時開很多帳號跑 ChatGPT、Claude、Midjourney 之類有用量冷卻限制的服務時，一次掌握所有帳號的狀態。

🔗 線上使用：`/tools/ai-cooldown/`（或見倉庫根目錄 [README](../../README.md) 的完整網址）

## 主要功能

- **新增紀錄**：填入「AI 網站」「帳號」「冷卻時間（天／時／分）」「註解」即可新增一筆倒數。
- **快速填入**：常見服務（ChatGPT、Claude、Perplexity、Midjourney、Gemini、Copilot）有一鍵按鈕，點一下自動帶入網站名稱。
- **即時倒數狀態**：每筆紀錄依剩餘時間自動顯示「已就緒 / 冷卻中 / 過期」狀態，表格每 5 秒自動刷新一次。
- **編輯 / 刪除**：點列表中的紀錄可以修改內容；刪除前會要求再次確認。
- **重置 / 清空**：
  - 「重置全部」：把所有紀錄的冷卻時間重新從現在開始倒數。
  - 「清空」：整批刪除所有紀錄。
- **排序與篩選**：可依「名稱 / 時間 / 星號」排序，並用上方篩選框依關鍵字過濾網站或帳號。
- **星號標記**：點星號圖示可以把重要的紀錄標記起來，排序時優先顯示。
- **桌面通知（選用）**：
  - 先打開「通知總開關」並允許瀏覽器通知權限。
  - 針對個別紀錄勾選「🔔 就緒時通知我」，冷卻結束時就會跳出系統通知。
  - 兩層開關都要打開才會真的發送通知，避免不小心被灌通知。
- **主題／語言**：右上角可切換暗／亮色主題與中／英介面，設定會與其他工具共用（見倉庫根目錄 README 的說明）。

## 使用方式

1. 在表單中選好或輸入「AI 網站」「帳號」，設定冷卻時間（例如 5 小時 30 分），可加註解方便辨識。
2. 按「新增」送出，紀錄會出現在下方表格，開始倒數。
3. 冷卻結束後狀態會自動變成「已就緒」；如果有開通知，也會跳出系統通知提醒你。
4. 需要重新計時時，直接點該筆紀錄「重置」，或用上方「重置全部」一次重來。

## 資料儲存

所有紀錄都存在瀏覽器的 `localStorage`，只存在你目前使用的這台裝置、這個瀏覽器裡，不會上傳到任何伺服器。清除瀏覽器資料或換裝置、換瀏覽器，紀錄不會跟著走。
